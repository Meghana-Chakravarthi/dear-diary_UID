# Dear Diary 📔

A Flutter-based diary application designed to make recording daily thoughts, personal experiences, and cherished memories simple and enjoyable.

## ✨ About the Project

Dear Diary is a digital journaling application developed using Flutter and Dart. It aims to provide a simple, user-friendly space for documenting everyday moments and personal reflections.

## 🛠️ Built With

- Flutter
- Dart
- Visual Studio Code
- Git and GitHub

## 🚀 Getting Started

### Prerequisites

- Flutter SDK
- Dart SDK
- Visual Studio Code or another supported IDE
- An emulator or compatible device

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Meghana-Chakravarthi/dear-diary_UID.git
   ```

2. Navigate to the project folder:

   ```bash
   cd dear-diary_UID
   ```

3. Install dependencies:

   ```bash
   flutter pub get
   ```

4. Run the application:

   ```bash
   flutter run
   ```
